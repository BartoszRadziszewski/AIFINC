## 🧭 Nawigator 8 Rozdziałów Projektu Końcowego (Wymogi ALK & ACCA)

Struktura dysertacji dyplomowej została podzielona na 8 powiązanych z programem studiów rozdziałów:
1. **Rozdział 1:** Wstęp i zdefiniowanie problemu biznesowego controllingu wybranej spółki WIG140.
2. **Rozdział 2:** Zgodność z regulacjami prawnymi (EU AI Act, RODO, wytyczne EBA/KNF) oraz aspekty etyczne (XAI).
3. **Rozdział 3:** Projektowanie architektury rozwiązania AI (BPMN 2.0, integracja ERP/EPM, chmura hybrydowa).
4. **Rozdział 4:** Zarządzanie danymi i inżynieria cech (Data Quality, Data Mesh, pipeline ETL/ELT, przeciwdziałanie dryfowi).
5. **Rozdział 5:** Wybór modeli AI, uczenie i ewaluacja (modele ML/DL, metryki biznesowe i techniczne, walidacja TimeSeries).
6. **Rozdział 6:** Implementacja i wdrożenie produkcyjne MLOps (konteneryzacja Docker/K8s, CI/CD, testy UAT, procedury fallback).
7. **Rozdział 7:** Zarządzanie zmianą organizacyjną (metodyka ADKAR), kultura AI First i dokumentacja techniczna.
8. **Rozdział 8:** Podsumowanie, ocena efektów biznesowych, weryfikacja ROI/NPV/TCO i roadmapa rozwoju CVO.

Nawigator zawiera interaktywną listę 41 punktów kontrolnych z automatycznym przeliczaniem postępu prac.

## 🛠️ Architektura Techniczna

* **Zero-Dependency:** Całość aplikacji zawarta jest w jednym pliku `index.html`.
* **Zero Zewnętrznych CDN:** Brak ryzyka niedostępności zewnętrznych bibliotek; pełna prywatność danych (przechowywanie koszyka i checklisty w `localStorage`).
* **Wymogi CSS:** Zgodność ze specyfikacją stylistyczną tabel i hiperłączy (`a { text-decoration: none; color: #464feb; }`, `tr th, tr td { border: 1px solid #e6e6e6; }`, `tr th { background-color: #f5f5f5; }`).
* **Wsparcie dla Dark Mode:** Dynamiczne przełączanie motywu z zachowaniem optymalnego kontrastu.
* **Hosting:** GitHub Pages w repozytorium [BartoszRadziszewski/AIFINC](https://github.com/BartoszRadziszewski/AIFINC).
